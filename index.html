I'm a third-year Software Engineering student with a sharp focus on building practical, deployable AI systems. My work sits at the intersection of machine learning and production software—where research meets reality.

My flagship project is an AI-powered ambulance monitoring system that uses object detection, real-time vehicle tracking, and license plate recognition (YOLOv8 + Tesseract + OpenCV) to solve real traffic safety challenges in Indian cities.

Beyond computer vision, I build cross-platform mobile apps with Flutter, create ML prediction pipelines, and architect end-to-end Flask REST APIs that put models into production. I care deeply about the full stack—from training to deployment.

Currently diving deep into PyTorch, CUDA acceleration, and scalable MLOps patterns. Always building. Always shipping.
